# Интерактивное приглашение — обновлённая версия

## Что изменено
- Дата и время обязательны (проверка уже была, оставлена).
- Перед переходом к пожеланиям требуется выбрать хотя бы один вариант еды/места, активности и настроения.
- В финальной сводке кнопка отправляет план в Telegram через Google Apps Script.
- Токен Telegram-бота не хранится в клиентских файлах сайта.
- Адаптивная вёрстка подходит для Safari на iPhone.

## Часть 1. Создать Telegram-бота
1. Открой Telegram и найди `@BotFather`.
2. Отправь `/newbot`, выполни инструкции и сохрани выданный токен. Не публикуй его и никому не отправляй.
3. Открой созданного бота по ссылке, которую выдаст BotFather, и нажми **Start**.
4. Чтобы получить свой chat ID, открой в браузере адрес, заменив `BOT_TOKEN` на токен бота:
   `https://api.telegram.org/botBOT_TOKEN/getUpdates`
   В ответе найди `message` → `chat` → `id`. Это число — твой `TELEGRAM_CHAT_ID`.
   Если `result` пустой, отправь боту ещё одно сообщение и обнови страницу.
5. Не отправляй ссылку `getUpdates` другим: в ней находится секретный токен. После настройки не сохраняй эту ссылку в публичных файлах.

## Часть 2. Настроить безопасную серверную отправку
1. Открой `https://script.google.com/` под своим Google-аккаунтом и создай новый проект.
2. Удали примерный код и вставь содержимое файла `telegram_backend.gs`.
3. Открой **Project Settings / Настройки проекта** → **Script properties / Свойства скрипта** → добавь:
   - `TELEGRAM_BOT_TOKEN` — токен из BotFather;
   - `TELEGRAM_CHAT_ID` — числовой ID своего чата.
4. Нажми **Deploy / Развернуть** → **New deployment / Новое развёртывание**.
5. Тип выбери **Web app / Веб-приложение**.
6. **Execute as / Выполнять от имени:** Me / Я.
7. **Who has access / У кого есть доступ:** Anyone / Все. Это нужно, чтобы посетитель сайта мог отправлять ответ без входа в Google. Поскольку URL публичный, не публикуй его отдельно от сайта и учитывай, что любой, кто узнает URL, может пытаться отправлять запросы. В коде есть простой лимит частоты запросов, но он не является полноценной защитой от злоупотреблений.
8. Разреши запрошенный доступ Google и заверши развёртывание.
9. Скопируй URL веб-приложения, который заканчивается на `/exec`.

## Часть 3. Подключить endpoint к сайту
1. Открой `config.js`.
2. Найди:
   ```js
   telegram: {
     webAppUrl: ""
   },
   ```
3. Вставь URL из предыдущего шага внутрь кавычек, например:
   ```js
   telegram: {
     webAppUrl: "https://script.google.com/macros/s/ТВОЙ_ID/exec"
   },
   ```
4. Сохрани файл. Токен бота в `config.js`, `app.js` или других файлах сайта не указывай.

## Часть 4. Опубликовать сайт бесплатно для iPhone
Самый простой вариант — GitHub Pages.

1. Создай/войдите в аккаунт на `https://github.com/`.
2. Создай новый репозиторий, например `invitation`, выбери **Public**.
3. Загрузи в корень репозитория файлы сайта: `index.html`, `style.css`, `app.js`, `config.js`. Файл `telegram_backend.gs` можно не загружать в репозиторий: он нужен только для копирования в Apps Script. Не загружай секретный токен.
4. В репозитории открой **Settings** → **Pages**.
5. В разделе **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/(root)`, затем **Save**.
6. Подожди публикации и открой адрес вида `https://ТВОЙ-USERNAME.github.io/invitation/`.
7. Отправь эту ссылку на iPhone и открой в Safari. Через меню «Поделиться» → «На экран Домой» можно добавить значок сайта.

Если позже изменишь файлы, загрузи их поверх старых в тот же репозиторий. GitHub Pages обновит сайт автоматически через некоторое время.

## Как проверить
1. Открой опубликованный сайт на телефоне.
2. Пройди приглашение и попробуй продолжить, не выбирая дату/время или варианты еды, активности и настроения: появится ошибка.
3. Выбери все обязательные поля, дойди до итоговой сводки и нажми «Отправить ответ».
4. Проверь чат, ID которого записан в `TELEGRAM_CHAT_ID`.

## Важные ограничения
- Отправка настроена на один конкретный Telegram-чат — тот, чей ID указан в свойствах скрипта.
- При публикации сайта бот не получает автоматически список посетителей; он получает только отправленные ответы.
- Из-за режима `no-cors` страница не может прочитать ответ Google Apps Script. Поэтому сообщение «Запрос отправлен» означает, что браузер передал запрос в сеть, а не гарантирует доставку в Telegram. Если сообщение не пришло, проверь настройки скрипта и бота.
- Google Apps Script и GitHub Pages имеют лимиты использования; это бесплатная схема для небольшого личного проекта.
- Перед реальным использованием протестируй отправку на своём устройстве.
